# Snake Water Gun Championship 🐍💧🔫

 A GUI-based Snake Water Gun game built with Python and Tkinter.

## Features

 Interactive GUI
 Voice announcements using pywin32
 Live Scoreboard
 Champion declaration
 Random computer moves

## Technologies Used

 Python
 Tkinter
 pywin32

## Installation


 pip install pywin32

## Run

 python main.py
